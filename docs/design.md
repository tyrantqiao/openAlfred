# openAlfred 设计说明

> Windows 版 Alfred 类启动器。交互模型参考 Alfred，视觉语言参考 Apple iOS / macOS Spotlight。
> 高保真原型见 [`mockups/index.html`](mockups/index.html)（浏览器直接打开，含 6 个场景）。

## 1. 设计原则

1. **单一输入框**：所有功能收敛到一个搜索框，靠关键词与前缀路由，不设标签页/侧边栏。
2. **即输即现**：无「搜索」按钮，输入停顿了即出结果，结果列表实时更新。
3. **克制留白**：空状态只有输入框与功能提示条；结果条数默认最多 8 条，宁可少不可乱。
4. **单一强调色**：全局只用一个品牌色（iOS 蓝），其余全部来自灰阶层级。

## 2. 视觉规范（Design Tokens）

### 2.1 配色令牌

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `accent` | `#007AFF` | `#409CFF` | 选中项文字、结果大数字、主按钮 |
| `text-primary` | `#1C1C1E` | `#F2F2F7` | 标题、输入文字 |
| `text-secondary` | `#8E8E93` | `#98989F` | 副标题、路径、时间 |
| `text-tertiary` | `#C7C7CC` | `#636366` | 占位符 |
| `bg-window` | `rgba(255,255,255,0.82)` | `rgba(38,38,46,0.86)` | 窗口底（叠加 Mica 毛玻璃） |
| `bg-selected` | `rgba(0,122,255,0.10)` | `rgba(10,132,255,0.22)` | 选中行背景 |
| `separator` | `rgba(60,60,67,0.12)` | `rgba(255,255,255,0.10)` | 分隔线、描边 |
| `success` | `#34C759` | 同左 | JSON 校验通过 |
| `danger` | `#FF3B30` | 同左 | JSON 语法错误提示 |

### 2.2 形状与间距

- 圆角：窗口 `18px`，结果卡片 `12px`，图标容器 `10px`，胶囊标签 `999px`
- 间距：8pt 栅格；结果行内边距 `12/14`，行间 `2`，图标与文字间距 `14`
- 描边：窗口 1px 白色 35% 透明度高光描边（浅色）/ 白色 14%（深色）
- 阴影：`0 24px 64px rgba(0,0,0,0.28), 0 2px 8px rgba(0,0,0,0.12)`

### 2.3 字体

| 层级 | 字号/字重 | 用途 |
|---|---|---|
| 输入文字 | 21px / Regular，字距 -0.01em | 搜索框 |
| 结果大数字 | 32px / Bold，等宽数字 | 计算器结果 |
| 标题 | 15px / Semibold | 结果主标题 |
| 副标题 | 12.5px / Regular | 路径、摘要、时间 |
| 等宽 | Cascadia Mono 12.5px, 行高 1.7 | JSON、算式回显 |

字体族：`Segoe UI Variable` → 中文回退 `Microsoft YaHei UI`；代码 `Cascadia Mono`。

### 2.4 材质

- Windows 11：`Mica` 背衬透出桌面色彩（WPF-UI `MicaBackdrop`）
- Windows 10 降级：窗口底色提高不透明度至 96%，接近纯色

## 3. 交互规范

### 3.1 唤起与窗口行为

| 行为 | 规则 |
|---|---|
| 唤起/隐藏 | 全局快捷键 `Alt+Space`（可在设置中改），Toggle 式 |
| 最小化 | 搜索框右侧最小化按钮：默认收进系统托盘常驻后台（可关，改用系统最小化），首次收进时气泡提示一次 |
| 关闭 | 关主窗口 = 收进托盘，进程不退出；退出仅能通过托盘菜单「退出」 |
| 启动 | 默认显示主窗口；可配置「启动后最小化到托盘」（仅创建句柄注册热键，不弹窗口）；重复启动时唤起已有实例 |
| 位置 | 屏幕水平居中，顶边位于屏幕高度 1/8 处（Spotlight 式） |
| 尺寸 | 宽 640px 固定，高度随内容自适应，上限为屏幕 2/3 |
| 层级 | `Topmost`，无边框、不在任务栏显示 |
| 失焦 | 自动隐藏（可配置关闭）；打开设置窗口时例外 |
| 动画 | 出现：透明度 0→1 + 96%→100% 缩放，120ms Ease-Out，作用于内容根元素（Window 本体不支持 RenderTransform）；消失仅隐藏 |

### 3.1.1 可配置唤起热键

- 默认 `Alt+Space`；存于 `settings.json` 的 `hotkey` 字段（字符串如 "Ctrl+Alt+Space"）
- 设置页提供录制器：点「修改…」后实时挂起旧热键（避免被系统拦截），按下新组合键即注册
- 校验：至少含一个修饰键（Alt/Ctrl/Shift/Win）或直接用 F1–F12；纯修饰键等待主键
- 注册失败（被占用）保留原绑定并提示，不丢失唤起能力；`Esc` 取消并恢复；「恢复默认」一键回到 Alt+Space

### 3.2 键盘操作

| 键 | 动作 |
|---|---|
| `↑` `↓` | 移动选中项（循环），首条结果默认选中 |
| `Enter` | 执行选中项动作（复制/打开/粘贴） |
| `Ctrl+Enter` | 文件结果：资源管理器中定位选中该文件 |
| `Esc` | 有输入内容时先清空，再按一次关闭窗口 |
| `Tab` | 补全功能关键词 |
| `Ctrl+Backspace` | 删除选中的剪贴板记录 |
| `Ctrl+C` | 复制计算器结果 / JSON（不关闭窗口） |

### 3.3 关键词路由

| 输入形态 | 路由 |
|---|---|
| 可解析为纯算式（如 `1+2*3`、`(3+4)/5`） | 计算器（置顶） + 文件检索兜底 |
| `app <名称>` | 应用启动器 |
| `clip [过滤词]` | 剪贴板历史（过滤） |
| `file <名称>` | 文件检索 |
| `json <内容>`，或输入内容可被识别为 JSON | JSON 转换器 |
| `time` / `time <城市>` / `time +3d` / `date` | 时间查询 |
| 无前缀普通词 | 应用启动器 + 文件检索 + 剪贴板内容命中混合结果，应用优先排序 |

路由实现：每个功能是一个 `IQueryProvider`（声明 `Keyword`、`Priority`、`CanHandle(raw)`），`QueryRouter` 收集所有 Provider 的结果并合并排序，单条输入可命中多个 Provider。

### 3.4 状态规范

- **加载态**：索引构建中时文件结果区显示灰色行「正在建立索引（n%）」，不阻塞其他功能
- **空态**：居中一行 `text-secondary` 小字说明（如「没有匹配的记录」），不显示插画
- **错误态**：仅计算器与 JSON 使用红色 `#FF3B30` 文字提示原因，其余功能静默不显示
- **结果上限**：每 Provider 最多 5 条，总列表最多 8 条

## 4. 信息架构（功能模块 I/O 定义）

### 4.1 计算器
- 输入：算式字符串；输出：主结果（数值）+ 辅助表示（科学计数法/分数）
- 支持：`+ - * / % ^ ()`、`sin cos tan sqrt log ln`、百分号换算（`20% of 80`）、负数
- 动作：`Enter` / `Ctrl+C` 复制结果；数字使用 `double`，整数结果去掉小数点尾巴
- 错误：表达式不完整时**不显示**结果行（避免打扰）；除零等语义错误显示红色小字

### 4.2 应用启动器
- 数据源：用户级与全体用户级开始菜单 `Programs` 目录下的 `.lnk` / `.url` 快捷方式（同名时用户级优先）
- 列表项：应用名（去扩展名）、分类（Programs 下子文件夹名，如「应用 · Visual Studio Code」）
- 匹配：与文件检索同一模糊打分，额外 +300 分使应用命中优先于同名文件
- 动作：`Enter` 直接 ShellExecute 快捷方式（由 Windows 解析目标，无需解链）；`Ctrl+Enter` 在资源管理器中定位快捷方式
- 限制：不索引 Microsoft Store 应用（其入口不在开始菜单文件系统内，v2 候选）

### 4.3 剪贴板历史
- 记录：文本 + 图片（图片存 PNG 文件引用），上限 200 条 FIFO，敏感窗口（密码管理器）可配置排除
- 存储：`%APPDATA%\openAlfred\clipboard.json` + `images/` 目录
- 列表项：内容摘要（首行，2 行截断）、类型图标、相对时间（2 分钟前 / 今天 14:02 / 昨天）
- 动作：`Enter` 写回剪贴板 → 隐藏窗口 → `SendInput` 模拟 `Ctrl+V` 粘贴回原窗口
- 空态：「剪贴板历史为空 · 开启后复制的内容会出现在这里」

### 4.4 文件检索
- 索引范围：`%USERPROFILE%`、Desktop、Documents、Downloads（深度默认 8 层，可配置）
- 索引：文件名内存索引 + `FileSystemWatcher` 增量维护；启动后后台构建，重建期间不可用不阻塞其他模块
- 匹配：模糊打分（连续前缀 > 词首 > 包含 > 子序列），文件夹结果带「（文件夹）」后缀
- 列表项：文件名（命中部分不高亮，保持简洁）、完整路径、修改时间 + 大小
- 动作：`Enter` 以默认程序打开；`Ctrl+Enter` 资源管理器定位

### 4.5 JSON 转换
- 输入：`json ` 前缀，或粘贴内容自动识别（首字符 `{` / `[` 尝试解析）
- 输出：语法高亮格式化视图（key/str/num/bool 四色）+ 状态行（合法/错误、字段数、字符数）
- 动作：`复制格式化`（缩进 2）、`压缩`（单行）、错误时显示出错行列与出错上下文片段
- 超长内容：只渲染前 40 行，尾部显示「… 共 n 行，Enter 复制全文」

### 4.6 时间查询
- `time`：本机当前时间 —— 大号时钟 `HH:mm` + 时区偏移 + 中文星期 + ISO8601 全量
- `time <城市/时区>`：如 `time 东京`、`time New York`、`time UTC+8`，显示相对本机的快/慢
- `time +3d` / `time -2h`：相对时间换算，显示结果日期
- 动作：`Enter` 复制 ISO8601 字符串

## 5. 里程碑

| 阶段 | 内容 | 出口 |
|---|---|---|
| M0（本阶段） | 设计稿：HTML 原型 + 本文档 | 确认视觉/交互方向 |
| M1 | 工程骨架 + 主窗口 + 快捷键 + QueryRouter + 计算器 | 唤起可输入可算 |
| M2 | JSON + 时间 | 五关键词路由全部可用 |
| M3 | 剪贴板历史 + 文件索引检索 | 全功能可用 |
| M4 | 设置窗口、托盘、深浅主题、动画打磨、单测 | 交付 exe |
